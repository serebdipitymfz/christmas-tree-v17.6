# 🎄 christmas-tree-v17.6（手势交互版）

Grand Luxury Tree v17.6 — Three.js 粒子圣诞树，支持四种摄像头手势与平滑状态过渡，并兼容手机微信内置浏览器。

**在线预览：https://serebdipitymfz.github.io/christmas-tree-v17.6/**

## 手势交互（需摄像头，微信内置浏览器除外）

| 手势 | 效果 |
| --- | --- |
| ✊ 握拳 | 回到聚合态（圣诞树） |
| 🖐 张开五指 | 进入散开态（星云） |
| 🔄 张开手掌旋转 / 移动 | 在散开态下平滑调整相机角度 |
| 🤏 捏合抓取 | 抓住照片，进入照片放大态 |

- 手势需连续识别 4 帧（抓取 3 帧）才触发，状态切换后有 650ms 冷却，避免抖动误触。
- 所有状态之间使用 `morph` 值在树形/星云位置间连续插值，粒子自转、缩放、雪花同步渐变，不是硬切换。
- 相机角度通过轨道目标值缓动追随手势，旋转和位移都会改变视角。

## 兼容性

- Three.js 及插件打包为经典脚本内联进 `index.html`，页面本身零外部依赖。
- Google Fonts 改为系统字体栈，无需联网。
- MediaPipe 手势模型与 wasm 本地托管在 `mediapipe/`，按需加载；微信内置浏览器不加载手势资源。
- 微信里摄像头手势不可用（环境限制），但触摸拖动旋转、双指缩放、按钮切换形态、照片与音乐等功能全部可用。

## 其他操作

| 操作 | 效果 |
| --- | --- |
| 拖动 / 单指滑动 | 旋转场景 |
| 双指缩放 | 缩放 |
| 聚合 / 散开 按钮（或空格 / Z） | 切换圣诞树 / 星云形态 |
| 抓图（或 X） | 保存当前画面 |
| 设置 | 打开文字、音乐、粒子等设置面板 |
