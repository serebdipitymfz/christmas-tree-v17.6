# 🎄 christmas-tree-v17.6

Grand Luxury Tree v17.6 — 单文件 Three.js 粒子圣诞树（手势控制 / 照片 / 背景音乐 / 雪）。

在线预览（源仓库）：https://liq47317-boop.github.io/christmas-tree-v17.6/

- 单文件实现：index.html
- 交互：鼠标拖拽旋转、空格聚合/散开、摄像头手势控制
- 可上传自己的照片、切换背景音乐

## 部署到 GitHub Pages（你自己的账号）

由于当前连接的 GitHub 集成只有**只读权限**，无法自动建仓/推送，请按以下步骤手动完成：

1. 在 GitHub 新建一个**公开**仓库，名称建议 `christmas-tree-v17.6`。
2. 把本目录下的 `index.html` 和 `.nojekyll` 上传到仓库根目录。
3. 进入仓库 **Settings → Pages**，"Build and deployment" 选择 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
4. 等待 1-2 分钟，访问 `https://<你的用户名>.github.io/christmas-tree-v17.6/`。

> `.nojekyll` 用于让 GitHub Pages 直接提供以点开头的文件/目录，单文件站点可保留。
