# 🎄 christmas-tree-v17.6

Grand Luxury Tree v17.6 — 单文件 Three.js 粒子圣诞树（手势控制 / 照片 / 背景音乐 / 雪）。

**在线预览：https://serebdipitymfz.github.io/christmas-tree-v17.6/**

- 单文件实现：`index.html`
- 交互：鼠标拖拽旋转、空格聚合/散开、摄像头手势控制
- 可上传自己的照片、切换背景音乐
- 部署方式：GitHub Pages，来源 `main` 分支根目录

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 鼠标拖拽 / 单指拖动 | 旋转场景 |
| 空格 | 聚合（圣诞树） |
| Z | 散开（星云） |
| X | 抓取照片 |
| H | 显示 / 隐藏界面 |
| 摄像头 | 手势控制（捏合抓图、张手散开、握拳聚合） |
